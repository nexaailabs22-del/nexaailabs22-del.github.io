# Nexa AI Labs - sitio web

Página de una sola sección publicada con GitHub Pages en https://nexaailabs.com.ar (DNS en Cloudflare, registros con nube gris).

- `index.html`: toda la página.
- `logo.png`: el logo (se usa en la página, el ícono y la vista previa al compartir).
- Links de Instagram y Facebook: buscar `link-instagram` y `link-facebook` en `index.html`.
